Signing up for a weekly program

Five ways volunteers could see all planned slots and sign up for several at once, including repeating the same weekday and time for the next few weeks. Each option below is clickable: tick slots, pick how many weeks to repeat, and press Register. Nothing is saved; it is the same demo data in every option.

Decided (7 Oct 2026)

Option C: two-week calendar (a week per row, ‹ › arrows, month shown) above a list of the next 2 weeks, with "Show 2 more weeks". Tick several slots across days and register once, repeating "next 4 / 8 dates" or the whole program (daily sessions: next 7 / 14 days).

Sheet: a new sheet and page link for this program; organisers fill Program plan (daily, weekdays, weekly, every 2 weeks, monthly, one-off; from/until), and a weekly script fills Slots. The page reads only the coming weeks.

Rules: release any single date until 12 hours before it starts; registering stays open until the start. Cancelled dates show a red notice to those registered, and organisers get a one-tap WhatsApp list of them. Option E (phone calendar) may come later.
