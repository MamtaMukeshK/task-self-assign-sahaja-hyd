Speaker Self-Assign: complete setup guide

One page, everything included. Follow the parts in order, and use the blue Copy buttons for the code. Takes about 15 minutes on a laptop or desktop computer (not a phone).

What this sets up: a web page where volunteers open one link, pick a date (today or any later day), see that day's tab of the "Hyd 2026 permission" Google Sheet (every column), and tap Claim on a school that still has free slots. They can take as many schools as they like, as long as two of them don't start at the same time on the same day. A school can take several people, up to its "Total volunteers needed", and the page shows how many places are left and who is already on it. Their name and mobile are written straight into that row of the sheet, so the sheet and the page always show the same thing, and two people can never take the same school.

1Before you start

  • You need EDIT access to the real sheet. If the sheet shows a "View only" badge, or the Extensions menu is grey, stop here and ask the sheet owner to make you an Editor (or to do these steps).
  • Use a personal Gmail account if you can. Some company or school accounts don't allow "Anyone" to open the page (Part 7).
  • The page runs under your Google account. Everything volunteers claim is written into the sheet as you, and the sheet's version history will show your name for those edits. That's normal.
  • Use a laptop or desktop with Chrome, Edge, Safari or Firefox.

2Check the sheet

  1. Time zone: in the sheet, open File → Settings. Time zone must be (GMT+05:30) India Standard Time. Change it if needed, then click Save settings.
    The page uses this to decide which day is "today": it opens on today's tab and lists today and later days in its date picker.
  2. Tab names: each day's tab must be named like 27-Sep, 28-Sep, 1-Oct or 01-Oct (day, dash, 3-letter month). Other tabs like Summary, cancel or Dummy-26-Sep are ignored, and so are past days.
  3. Speaker list (optional): a tab named Speaker (or Speakers) with a Speaker column. The page offers these names in a dropdown, alphabetically, so people don't retype them. Everyone registered through the page is saved there: a new name gets a new row (with the next Sr. No.), and a known name without a number gets it filled in. The first time, the page adds a Mobile column in the tab's first empty column. Other columns (Language, dates) are never touched. If there's no such tab, the page creates one called Speakers.
  4. Time (for clash checks): a column whose title contains Time. The page reads the start time from whatever is typed (10.30 A.M, 3:30-4:30 PM, 14:00…). If a volunteer tries to take two schools that start at the same time on the same day, the second is refused. A blank Time, or text like "to be confirmed", can't be checked, so fill in times where you can. Without AM/PM, 1 to 5 o'clock counts as afternoon. The end time (after "to" or a dash, e.g. "2pm to 3pm") is used to grey out slots once they're over; with no end time, a slot is taken to last 1 hour.
  5. Header row: on each day tab, row 1 holds the column titles, and exactly one title contains the words Speaker and Name, for example "Sahaja Yoga ( IND) Speaker Name" or "Sahaja Yoga Speaker Name". That is the only column the page ever writes into, listing everyone on the school, one person per line.
  6. Volunteers per school (optional): to let a school take more than one person, have a column titled Total volunteers needed (any title containing "total" and "volunteer" works) and put the number in each row. A blank cell, or no such column, means 1 person. 0 closes a school.
  7. Still needed (optional): a column titled like count of Volunteers still needed (containing "still" and "volunteer") is updated by the page on every claim and release. If you put your own formula in it, the page leaves it alone.

3Open the script editor

  1. In the real sheet, click the menu Extensions → Apps Script. A new browser tab opens.
  2. At the top left, click Untitled project, type Speaker Self-Assign, and click Rename.
Open the editor from the sheet's Extensions menu, not from script.google.com. That's what connects the script to this sheet.

4Paste Code.gs

  1. On the left under Files, click Code.gs. It contains a few starter lines.
  2. Click inside the code area, press Ctrl+A (Mac: ⌘+A), then Delete, so it's completely empty.
  3. Click the blue Copy Code.gs button below, then click in the empty code area and paste with Ctrl+V (Mac: ⌘+V).
  4. Save with Ctrl+S (Mac: ⌘+S). The orange dot next to the file name disappears.
  5. Check: the first line is /** and the last line starts with function cacheKey_. Do not change anything in it. In particular, SHEET_ID and TAB_NAME_OVERRIDE must both stay ''.

6Give permission (one time)

  1. Click Code.gs on the left. The Run button only appears while a .gs file is open.
  2. In the toolbar, the dropdown next to Debug lists functions: choose getState.
  3. Click ▷ Run. A box says Authorization required: click Review permissions and choose your account.
  4. Google shows "Google hasn't verified this app". This is normal for your own scripts, and the "developer" it names is you. Click Advanced (bottom left), then Go to Speaker Self-Assign (unsafe).
  5. Click Allow. It asks to see and edit your spreadsheets, which is how it writes names into the sheet.
  6. The Execution log opens at the bottom:
    • "Execution completed": done, go to Part 7.
    • "There are no day tabs for today or later yet": the code works; there's just no tab named like 30-Sep for today or a later date. You can still go on.
    • Any other red message: see Part 11.

7Publish the page

  1. Top right: click the blue Deploy button → New deployment.
  2. Next to Select type, click the gear icon → Web app.
  3. Fill in:
    FieldSet to
    Descriptionv1
    Execute asMe (your email)
    Who has accessAnyone (not "Anyone with Google account")
  4. Click Deploy (allow permission again if asked).
  5. Copy the Web app URL. It's long and ends in /exec. This is the volunteers' link. Click Done.

8Test it

  1. Open the /exec link in a new browser tab. You should see "Day: [date]" with a Date picker next to it, every column of that day's tab, plus two extra columns at the left: Slots left and SY Speaker Name (who is on it, with phone numbers; the sheet's own Speaker Name column isn't repeated). Each school with a free slot has a blue Claim button. A grey Google bar at the top ("created by a Google Apps Script user") is normal and can't be removed.
  2. Type a test name and a 10-digit mobile, then click Claim on one open row. It turns green.
  3. In the sheet, that row's Speaker Name cell now has a new line with the name and mobile, below anyone already there. No other cell changed.
  4. Back on the page, click Release. Only your line disappears from the cell; anyone else stays.
  5. Optional: open the link on your phone too, and try to claim the same row from both at the same time. Both are added: a school can go over its total, and anyone beyond it shows in red, marked "over limit".
  6. Tick Register others, list one person per line (name then 10-digit mobile), and click Claim. They're added as Ravi 9123456789 (via [your name]), and you can remove them with the ✕ next to their name.
All good? Then it's live. Share the link (Part 9).

9Share it with volunteers

Paste your /exec link into this message and send it:

Message for volunteers 
🙏 To pick schools for the program, open this link:
PASTE-THE-/exec-LINK-HERE

1. Type your name and mobile number at the top (only needed the first time).
2. Choose the date at the top, then tap "Claim" next to a school that still has slots left.
   You can take several schools, just not two at the same time on the same day.
   Registering a group? Tick "Register others", then tick names under "Choose speakers"
   (or type new ones, one per line: name, then 10-digit mobile). If a speaker has no number saved yet,
   you'll be asked for it once; after that it's remembered.
3. Your row turns green: you're on it, and your name shows in the main sheet.
4. Changed your mind? Tap "Release".
The page refreshes every 15 seconds.

10Daily rules for organisers

Do thisWhy
Name each day's tab like 28-Sep / 1-Oct / 01-Oct, one tab per date. That's how the page lists dates in its picker.
Keep the titles in row 1, with exactly one title containing "Speaker" and "Name". That's the column the page writes into.
A school has room while it has fewer people than its "Total volunteers needed" (1 if blank). To remove someone, delete their line from the Speaker Name cell. Keep notes like "12 sessions" out of the Speaker Name column: they count as a person. The page shows the change within about 15 seconds.
Keep typing in the sheet as usual (including name + number in one cell). The page always reflects the sheet. Rows you fill by hand show as taken.
The same link works every day. It opens on today's tab (or the next day that has a tab). Past days stay in the date list, marked "(past)", but are grey and view-only; slots whose end time has passed today are grey too.
Fill in the Time column. That's what stops one volunteer being booked at two schools at the same time.

11If something goes wrong

What you seeWhat it means / what to do
Extensions menu is greyYou only have View access. Ask the owner for Edit access.
"There are no day tabs (named like 30-Sep) yet"No tab is named like 1-Oct. Create or rename one. Also check the time zone (Part 2).
"… is not available any more"That day's tab was renamed or removed. Pick another date.
A grey page: "This day is over: view only"You picked a past date (marked "(past)" in the list). It can be looked at but not changed.
A grey row marked "Ended"That slot's end time today has passed, so it can't be claimed or changed. "Open only" hides these.
"Time clash: you are already on …"You already have a school starting at the same time that day. Release it first, or pick another time.
"Clashes with S No …" instead of a Claim buttonSame as above, shown before you click.
"…has no column in row 1 whose header contains "speaker" and "name""That day's tab has no Speaker Name title in row 1. Add or fix the title.
"…has several columns whose header contains…"Two titles contain both words. Rename one so only one does.
"Cannot read properties of null (reading …)"The script was created at script.google.com instead of from the sheet. Redo Part 3 from the sheet's Extensions menu.
A school in red, "Over by N", names in red "(over limit)"More people registered than it needs. Organisers decide who goes; anyone can Release or ✕ to bring it back within the limit.
"This school is closed (its total is 0)"Its "Total volunteers needed" is 0. Organisers can raise it in the sheet.
"Line N of "Register others" should be a name then a 10-digit mobile"Fix that line (e.g. Ravi 9123456789). Nobody is added until every line is valid.
"Time clash: Ravi is already on …. Nobody was added."Someone in your list already has a school at that time that day. Remove them from the list, or pick another school.
"Please enter a 10-digit mobile for … in Choose speakers"That speaker has no number saved yet. Type it in the small box next to their name; it's asked only once.
"First time: please enter your 10-digit mobile"Your name is on the speaker list but has no number yet. Type it once; it will be saved.
"Only Ravi or Priya can remove Ravi"People can remove themselves, and whoever registered them can remove them. Anyone else: ask an organiser to edit the sheet.
"Your name is not on this row"Release only works with the same name used to claim (capitals don't matter).
"That row was edited or moved…"An organiser changed that school's details (including "Total volunteers needed") or re-ordered rows after the page loaded. The page refreshes; check and claim again.
"Lots of people are claiming right now"Many claims arrived at the same second. Try again.
"Please enter a 10-digit mobile number"Type exactly 10 digits. Spaces are fine, and a leading +91 or 0 is accepted and removed.
"Who has access" doesn't offer "Anyone"Your account's organisation blocks it. Do the setup from a personal Gmail account that has edit access.
The page shows yesterday's tabTime zone is wrong. Fix it in File → Settings (Part 2).
You changed the code but the page didn't changeYou must publish a new version (Part 12).

12Changing or switching off the page later

  • Update the code (same link): paste the new code and save, then go to Deploy → Manage deployments, click the pencil, set Version: New version, and click Deploy.
    Do not use "New deployment" for updates, because that creates a different link.
  • Switch the page off: go to Deploy → Manage deployments, click Archive. The link stops working immediately.
  • Test on a copy first (optional): use File → Make a copy of the sheet after Part 5. The copy has its own copy of the script; publish that one to experiment without touching the real sheet.

13Good to know

  • Names are on trust. Anyone with the link can type any name, and register others. People can remove themselves, and whoever registered someone (shown as "via …") can remove them; organisers can always fix things in the sheet.
  • Privacy: everything on today's and later days' tabs, including phone numbers, is visible to anyone with the page link. That's the same as the sheet's current "anyone with the link can view" sharing.
  • Capacity: dozens of people can use it at the same time without problems.
  • Safety: the page only ever writes the Speaker Name cell of the row being claimed. It never adds, deletes or re-orders rows, and never touches other columns.
