Follow-up Program sign-up: complete setup guide

One page, everything included. Follow the parts in order and use the blue Copy buttons for the code. Takes about 20 minutes on a laptop or desktop computer (not a phone).

What this sets up: a new Google Sheet and its own page link for the Follow-up Program. Organisers type the regular sessions once (for example "every Saturday 6:30 PM at Ameerpet"); the sheet makes one row per date. Volunteers open the link, see the week as large day boxes, tick one or more sessions (and repeat them for the next 4 or 8 dates, or the whole program), register themselves and others, and release a single date up to 12 hours before it starts. The tour sheet and the tour page are not touched.
Organisers' video (about 2 minutes): watch how to fill in Program plan and run Slots - adding a plan line, the frequencies, Update slots now, which Slots columns you may change, cancelling a date and the WhatsApp list. (It shows a copy of the sheet's layout, not live Google Sheets.)

1Make the new sheet

  1. Go to sheets.new in your browser (signed in with the Google account that will own the program). A blank sheet opens.
  2. Click Untitled spreadsheet at the top left and type a name, e.g. Follow-up Program 2026.
Use the account that should own this. The page runs as that account, and only people with edit access to the sheet can change it.

2Open the script editor

  1. In the new sheet, click the menu Extensions → Apps Script. A new browser tab opens.
  2. At the top left, click Untitled project, type Follow-up Sign-up, and click Rename.
Open the editor from the sheet's Extensions menu, not from script.google.com. That's what connects the script to this sheet.

3Paste Code.gs

  1. On the left under Files, click Code.gs. It contains a few starter lines.
  2. Click inside the code area, press Ctrl+A (Mac: ⌘+A), then Delete.
  3. Click the blue Copy Code.gs button below, click in the empty code area and paste with Ctrl+V (Mac: ⌘+V).
  4. Save with Ctrl+S (Mac: ⌘+S).
  5. Check: the first line is /** and the last line starts with function norm_. Do not change anything in it.

5Set up the sheet and give permission (one time)

  1. Go back to the sheet's browser tab and reload it (F5). After a few seconds a new menu Program appears at the top, next to Help.
  2. Click Program → Set up the sheet (first time). A box says Authorization required: click OK / Review permissions and choose your account.
  3. Google shows "Google hasn't verified this app". This is normal for your own scripts, and the "developer" it names is you. Click Advanced, then Go to Follow-up Sign-up (unsafe), then Allow. It asks to see and edit your spreadsheets (to write names into the sheet) and to run while you're away (the Sunday-night update).
  4. If nothing else happens, click Program → Set up the sheet (first time) once more.
  5. A message says "Created: Program plan, Slots, Speakers. The weekly update (Sunday night) is on." Three new tabs appear at the bottom. You can delete the empty Sheet1 tab.
Set-up also sets the sheet's time zone to India and adds drop-down lists and notes on each column title (hover over a title to read who fills it). Running it again never changes tabs that already exist.

7Make the dates

  1. Click Program → Update slots now. A message says how many dates were added.
  2. Open the Slots tab: one row per date, sorted by date and time. This is what volunteers see.
  3. Open the Update report tab: it lists anything that needs you (for example a plan line with a mistake, which is skipped until fixed). It is replaced on every update.

The update also runs by itself every Sunday night (adds new dates for lines without an Until date, and applies plan changes).

Slots columnsWho changes them

Never delete a Slots row. To drop a date, set its Status to Cancelled (a deleted row comes back on the next update). A one-off date can be typed into an empty Slots row (Date, Start Time, End Time, Institution Name, Volunteers Needed); it gets its Slot ID and appears on the page after the next Update slots now.

8Publish the page

  1. In the Apps Script tab, top right: click the blue Deploy button → New deployment.
  2. Next to Select type, click the gear icon → Web app.
  3. Fill in:
    FieldSet to
    Descriptionv1
    Execute asMe (your email)
    Who has accessAnyone (not "Anyone with Google account")
  4. Click Deploy (allow permission again if asked).
  5. Copy the Web app URL. It's long and ends in /exec. This is the volunteers' link. Click Done.

9Test it

  1. Open the /exec link in a new tab. You should see the lotus header Follow-up Program, the week as large day boxes (today has a gold border), and below it the next 2 weeks of sessions. The bottom line shows v followup-…. A grey Google bar at the top is normal and can't be removed.
  2. Type a test name and a 10-digit mobile. Tap Select on a session, choose Just this date in the bar at the bottom, tap Register, check the list, tap Confirm. In the Slots tab that date's Volunteers cell now has the name.
  3. Tap Release on the card: the name disappears from the cell.
  4. Tap Who: Just me ▾ (under Mobile), add one person as Ravi 9123456789, register a date: it's written as Ravi 9123456789 (via [your name]), and the card shows a ✕ next to Ravi.
  5. Open the link on a phone too and try the language switch (English, తెలుగు, हिन्दी).
All good? Then it's live. If anything looked different from this description, tell Claude exactly what you saw (a screenshot helps): this is the first run on real Google.

11Day-to-day: changes and cancellations

  • Change a regular session (time, place, frequency, dates): edit its Program plan line, then Program → Update slots now. Future dates with nobody on them are updated; dates that already have volunteers are kept as they are and listed in the Update report for you to decide.
  • Cancel one date: in Slots set its Status to Cancelled. The page strikes it through, and everyone on it sees a red notice at the top. Then:
    1. Program → Cancellation WhatsApp list: everyone affected (also people registered by someone else) with a green Open WhatsApp button and a ready-written message. Tap each one and press Send. People without a mobile are marked "please phone".
    2. Program → Mark cancellation notices as sent: it names the dates and asks Yes/No. Say Yes only when everyone has been sent the message.
  • Who is coming: the Volunteers column of each date in Slots. Use Data → Create a filter on the Date column to see one day.
  • Privacy: as on the tour page, everyone with the link can see the names and mobiles on the page.

12If something goes wrong

What you seeWhat to do
No Program menu in the sheetReload the sheet and wait 10 seconds. Check Code.gs was saved (Part 3).
"There is no "Program plan" tab"Run Program → Set up the sheet (first time).
A plan line made no datesRead the Update report tab: it says what is wrong with that line (e.g. "Start is not a time like 6:30 PM").
Sessions show the wrong timeType the time with AM or PM in the plan, then Update slots now.
Dates are one day offFile → Settings → Time zone: choose (GMT+05:30) India Standard Time, then Update slots now.
The page says it can't load, or asks volunteers to sign inDeploy → Manage deployments: Who has access must be Anyone.
The page shows an old versionYou pasted new code but didn't publish a new version: see Part 13.

13Changing the code later

  1. Paste the new Code.gs and/or Index.html as in Parts 3 and 4, and save.
  2. Deploy → Manage deployments → click the pencil (edit) → Version: New version → Deploy. The link stays the same.
  3. Open the page and check the version number at the bottom.
